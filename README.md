# Task 2 - Customer Retention & Churn Analysis

## Project Overview

This project presents an interactive Customer Retention and Churn Analysis Dashboard developed in Microsoft Excel. The dashboard analyzes customer retention behavior and churn patterns to help businesses understand why customers leave and identify opportunities to improve customer loyalty and retention.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers and Filters
* KPI Cards
* Data Cleaning and Analysis

## Dataset

The dataset contains customer information and service-related details, including:

* Customer Status (Retained/Churned)
* Contract Type
* Internet Service
* Tech Support
* Payment Method
* Customer Demographics
* Subscription Information

The data was cleaned and analyzed to identify key factors influencing customer churn and retention.

## KPIs

The dashboard tracks the following Key Performance Indicators (KPIs):

1. Total Customers: 7,043
2. Churned Customers: 1,896
3. Retained Customers: 5,174
4. Churn Rate: 26.5%
5. Retention Rate: 73.5%

## Analysis Performed

* Overall churn and retention analysis.
* Churn distribution among customers.
* Churn by Tech Support availability.
* Churn by Internet Service type.
* Churn by Contract Type.
* Churn by Payment Method.
* Retention and customer loyalty assessment.

## Dashboard Features

* Interactive KPI cards.
* Churned vs Retained Customers visualization.
* Churn analysis by Tech Support.
* Churn analysis by Internet Service.
* Churn analysis by Contract Type.
* Churn analysis by Payment Method.
* Dynamic filtering using slicers.
* Clean and user-friendly dashboard layout.

## Key Insights

* The company retained 73.5% of its customers while 26.5% churned.
* Customers with Month-to-Month contracts exhibited the highest churn rate.
* Customers without Tech Support showed significantly higher churn.
* Fiber optic users experienced higher churn compared to other internet service types.
* Electronic check payments were associated with relatively higher customer churn.
* Long-term contract customers demonstrated stronger retention behavior.

## Recommendations

* Encourage customers to switch from Month-to-Month contracts to longer-term plans.
* Improve and promote Tech Support services to increase customer satisfaction.
* Investigate reasons behind high churn among Fiber Optic users.
* Offer incentives and loyalty programs for high-risk customers.
* Promote automatic payment methods to improve customer retention.
* Develop targeted retention campaigns for customers likely to churn.
